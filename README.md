# House Price Regression — TUIA (Aprendizaje Automático 1)

Predicción del **precio de viviendas** mediante modelos de **regresión lineal múltiple**, aplicando técnicas de preprocesamiento y optimización de hiperparámetros.

**Materia:** Aprendizaje Automático 1 — Tecnicatura Universitaria en Inteligencia Artificial (TUIA · UNR, Argentina)
**Integrantes:** Tomás Avecilla · Franco Calcia

## Objetivo

Implementar y comparar modelos de regresión para predecir el valor de las viviendas a partir de sus características, cubriendo el flujo completo: análisis exploratorio, preprocesamiento, entrenamiento, optimización de hiperparámetros y evaluación de métricas.

## Estructura del repositorio

- **`TP_regresion_AA1.ipynb`** — Notebook principal con todo el desarrollo: EDA, implementación de los modelos, optimización de hiperparámetros y evaluación.
- **`house-prices-tp.csv`** — Dataset utilizado para el análisis y el modelado.
- **`requirements.txt`** — Dependencias del proyecto.

## Requisitos

```bash
pip install -r requirements.txt
```

Luego abrir el notebook en Jupyter o Google Colab y ejecutarlo de arriba hacia abajo.

## Stack

`Python` · `pandas` · `scikit-learn` · `Jupyter`
